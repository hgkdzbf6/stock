## 后台实现

### 新增 API 端点

1. **更新用户信息** - `PUT /auth/profile`
   - 请求参数：
     - `full_name`: 姓名（可选）
     - `phone`: 手机号（可选）
     - `email`: 邮箱（可选）
   - 返回：更新后的用户信息

2. **修改密码** - `POST /auth/change-password`
   - 请求参数：
     - `old_password`: 当前密码
     - `new_password`: 新密码
   - 返回：成功消息

3. **上传头像** - `POST /auth/avatar`
   - 上传用户头像图片
   - 返回：头像 URL

- 危险操作提示

## 数据流程

### 加载用户信息
1. 组件挂载时调用 `loadUserProfile()`
2. 调用 `authService.getCurrentUser()`
3. 填充表单数据
4. 显示加载状态

### 更新用户信息
1. 用户填写表单
2. 点击"保存修改"
3. 调用 `authService.updateProfile()`
4. 更新成功后：
   - 显示成功消息
   - 更新 localStorage 用户信息
   - 重新加载用户信息
5. 更新失败显示错误消息

### 修改密码
1. 用户填写密码表单
2. 点击"修改密码"
3. 调用 `authService.changePassword()`
4. 修改成功后：
   - 显示成功消息
   - 清空表单
   - 自动登出
   - 跳转到登录页
5. 修改失败显示错误消息

### 上传头像
1. 用户点击头像
2. 选择图片文件
3. 格式和大小验证
4. 上传到服务器
5. 上传成功：
   - 显示成功消息
   - 重新加载用户信息
6. 上传失败显示错误消息
